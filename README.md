
# Sales Data Analysis & Reporting Using Python

## Project Overview
This project focuses on analyzing structured sales data using Python to extract meaningful business insights. The analysis includes revenue calculation, product-wise and category-wise performance evaluation, and monthly sales trend analysis. The project simulates real-world tasks performed by junior data analysts to support data-driven business decision-making.

## Objectives
- Create and analyze a structured sales dataset using Python
- Calculate total sales revenue and total number of orders
- Identify top-performing and low-performing products
- Analyze sales performance across different product categories
- Perform monthly sales trend analysis
- Summarize findings in a clear business-friendly format

## Tools & Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub

## Dataset Description
The dataset contains 100 sales records with the following attributes:
- order_id
- order_date
- product_name
- category
- quantity
- unit_price
- total_amount

The dataset represents realistic sales transactions across multiple product categories.

## Key Insights
- The total revenue generated from all sales is ₹23,648,780 across 100 orders.
- Laptop is the highest-selling product, contributing the largest share of total revenue.
- File Folder is the lowest-selling product due to its low unit price.
- The Electronics category generates the highest revenue because of high-value products.
- The Stationery category contributes the least to overall revenue.
- Monthly sales analysis shows noticeable variations in revenue across different months.
- Data visualizations clearly highlight differences in product and category performance.

## Output Files
- Week2_Sales_Data_Analysis.ipynb – Google Colab notebook containing the complete analysis
- week2_sales_analysis_output.csv – Final processed dataset exported from the analysis

## Conclusion
This project demonstrates how raw sales data can be transformed into useful business information using Python. The insights generated from this analysis help understand sales performance and support better business planning and decision-making.
